# .github/workflows/snake.yml

```yaml
name: Generate Contribution Snake

on:
  schedule:
    # Runs automatically once every day
    - cron: "0 0 * * *"

  workflow_dispatch:

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest

    timeout-minutes: 10

    steps:
      - name: Generate contribution snake
        uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}

          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Publish snake to output branch
        uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_branch: output
          publish_dir: ./dist
```

# Activating the Contribution Snake

After adding `.github/workflows/snake.yml`:

1. Push the files to your GitHub profile repository.
2. Open your profile repository.
3. Go to **Actions**.
4. Select **Generate Contribution Snake**.
5. Click **Run workflow**.
6. After it finishes, GitHub should create an `output` branch.
7. Reload your profile README.

The snake URLs use:

```text
https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/YOUR_GITHUB_USERNAME/output/github-snake.svg
```

and:

```text
https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/YOUR_GITHUB_USERNAME/output/github-snake-dark.svg
```

# Reliability Note

Most GitHub profile widgets are hosted by third-party open-source services.

Because of that, occasionally:

* a widget may load slowly,
* GitHub API rate limits may delay updates,
* statistics may be cached,
* a third-party hosting service may temporarily be unavailable.

For maximum long-term reliability, important professional information such as your:

* Experience
* Education
* Skills
* Projects
* Contact information

is written directly into your README instead of depending on external widgets.
